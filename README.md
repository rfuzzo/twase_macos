# TWASE for macOS (moved)

The macOS version of TWASE is now part of [TWASE](https://github.com/rfuzzo/TWASE), which builds and releases Windows and Mac from one repo. Download `TWASE-macOS-<version>.zip` from [TWASE's releases](https://github.com/rfuzzo/TWASE/releases); installation and usage are in its README.

This repository is archived. Its history is in TWASE, the macOS code is in `src/platform/macos/` there.
